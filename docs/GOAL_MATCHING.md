# CareerLens 0.7.0：求职目标匹配

## 本轮改了哪里

| 改动 | 用户能看到什么 |
| --- | --- |
| 统一筛选 | 就业问答、技能测评和岗位推荐共用城市、岗位类别、实习或校招、技术关键词、本人学历、最低月薪条件。目标城市无结果时，由用户选择是否查看其他城市。 |
| 自然语言整理与跨页联动 | 输入一句求职目标，可以整理成可编辑的条件草稿。识别出多个候选城市等歧义时，先选择或确认不限；分析结果或测评条件可带入推荐页。 |
| 可核对的技能缺口 | 先确定目标岗位，再计算覆盖和需求频次。每项待补技能显示需求样本数和有技能标签的样本总数，可以展开查看岗位编号、标签及来源标记。 |
| 限定证据的问答和练习 | 模型根据目标岗位证据生成问答；可为前 3 项待补技能生成小练习和验收产出。未配置、调用失败或校验不通过时，页面仍可显示规则结果。 |

账号、部署配置和岗位样本文件沿用原版。现有 DeepSeek 配置可复用，规则流程也可以单独运行。

## 演示步骤

1. 在项目根目录运行 `python scripts/start.py`，打开 <http://127.0.0.1:8000/ask>。就业问答、测评和推荐都可用访客身份体验。
2. 输入「我是在校本科生，会 Spring Boot 和 MyBatis，想找深圳 Java 后端实习。」点击「整理为求职条件」。核对城市为深圳、类别为后端开发、类型为实习、关键词为 Java、学历为本科，两项技能已经带入。
3. 点击「按这些条件分析」。当前数据命中 1 条：`JOB_0053` Java后端开发（实习转正）。展开待补技能 Docker，查看它对应的样本岗位。点击「生成补技能练习清单」，可看到练习和验收产出。
4. 点击「用本次分析条件匹配岗位」，再点「开始智能推荐」。这条岗位的技能覆盖是 **2/8**。勾选 Docker 后重新推荐，覆盖变成 **3/8**，Docker 从待补移到已掌握。这里演示的是技能填写后系统如何重算覆盖。
5. 保持深圳、后端开发、实习、本科四项，清空 Java 关键词并取消 Docker，再运行推荐。目标岗位共 3 条，其中 2 条记录了 Docker：`JOB_0053`、`JOB_0811`。目标样本数和按技能交集展示的推荐条数可以不同。

如果要演示没有结果的情况，把城市改为合肥并恢复 Java 关键词。此时不会返回其他城市；勾选跨城选项再运行，才能查看仍满足类别、招聘类型和学历条件的其他城市岗位。

## 实现与统计口径

- **硬条件**：类别按样本的 `job_category`；实习、校招按岗位标题明确标记识别，经验不限不推断为实习。最低期望月薪比较岗位薪资下限；本人学历与岗位要求比较。技术关键词可用「或」表示多个方向，空格分隔的多个关键词须在同一岗位命中。
- **技能数据**：岗位、技能次数、覆盖分和排序由后端从 `data/sample/jobs_sample.csv` 计算。岗位技能覆盖率为「已掌握的岗位技能项数 ÷ 岗位技能项数」，计算前会统一技能别名和去重；选择了类别或招聘类型的推荐按覆盖率排序。测评的综合覆盖分是展示的最多 5 条岗位覆盖分的平均值。技能需求频次的分母为当前目标岗位中有技能标签的记录数。技能分不是录用概率。
- **模型边界**：模型可以补充可编辑的求职条件草稿。问答只把检索到的最多 5 条目标岗位提供给模型，并检查岗位编号与原文摘录；它不能靠引用校验保证全部语义结论正确。练习清单的技能、频次和样本依据由后端决定，模型只负责补练习与验收产出。问答和练习在无对应样本或缺口时不调用模型。
- **样本边界**：来源为数据集中的原始标记，不代表实时招聘信息或对招聘网站逐条核验。案例数字只适用于本版本的 2,000 条样本。

| 入口 | 后端接口 | 主要实现 |
| --- | --- | --- |
| 共用求职条件 | `GET /api/job-goal/options` | `backend/job_matching.py`、`JobGoalFields.vue` |
| 求职草稿与问答 | `POST /api/job-goal/parse`、`POST /api/ask` | `backend/goal_assistant.py`、`backend/rag.py`、`AskPage.vue` |
| 测评与推荐 | `POST /api/skill-match`、`POST /api/recommend` | `backend/job_matching.py`、`SkillTestPage.vue`、`JobRecommendPage.vue` |
| 技能依据及练习清单 | `POST /api/job-goal/plan` | `backend/goal_assistant.py`、`SkillGapPanel.vue` |

复跑时，在新版的 Git 项目根目录执行：

```powershell
git worktree add --detach ../CareerLens-baseline 0cab786
python scripts/evaluate_job_goals.py --baseline ../CareerLens-baseline
```

脚本检查两份 CSV 一致，输出逐例数量、展示的岗位编号和不符合条件条数。不传 `--baseline` 时，只检查当前版本。以上是固定样本的筛选回归结果，不是大模型准确率。

本地验证覆盖了后端测试（116 通过，1 项独立 PostgreSQL 测试因无测试库跳过）、前端 6 项测试、生产构建以及本地前后端联动。新版模型链路使用模拟响应验证成功与回退，部署后应再用实际服务核验一次问答与练习清单。
